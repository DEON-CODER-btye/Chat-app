# Chat App 💬

A simple chat application built as a learning project using HTML, CSS, and JavaScript.

This project is currently under development. More features, improvements, and better UI will be added in the future.

## 🚀 Features Implemented

- Send messages
- Receiver auto messages
- Message timestamps
- Auto scroll to latest message
- Save chat messages using LocalStorage
- Restore previous messages after page refresh
- Separate sender and receiver message handling

## 🛠️ Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- LocalStorage API

## 📚 What I Learned

While building this project, I learned:

- DOM manipulation
- Creating and updating elements dynamically
- Handling user input
- Working with LocalStorage
- JSON.stringify() and JSON.parse()
- Managing data using arrays and objects
- Creating reusable functions
- Handling message flow between sender and receiver
