# Chat App 💬

A simple chat application built as a learning project using HTML, Tailwind CSS, and JavaScript.

This project is currently under development. The main goal of this project is to improve JavaScript skills by building real-world chat features and understanding how dynamic applications work.

## 🚀 Features Implemented

- Send messages
- Receiver auto messages
- Message timestamps
- Auto scroll to latest message
- Save chat messages using LocalStorage
- Restore previous messages after page refresh
- Separate sender and receiver message handling
- Typing effect for receiver messages
- Dynamic chat sidebar generation
- Fetching chat user data from JSON file
- Creating UI elements dynamically using JavaScript
- Displaying user name, last message, time, and unread message count dynamically

## 🛠️ Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Fetch API
- LocalStorage API
- JSON
