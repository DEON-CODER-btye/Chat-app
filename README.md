# Chat App 💬

A simple chat application built as a learning project using HTML, Tailwind CSS, and JavaScript.

This project is being developed to improve JavaScript skills by building a real-world chat application and understanding how dynamic applications, data management, and LocalStorage work together.

## 🚀 Features Implemented

- Send messages
- Receiver auto messages
- Message timestamps
- Auto scroll to latest message
- Sender and receiver message handling
- Typing effect for receiver messages
- Dynamic chat sidebar generation
- Fetching user data from a JSON file
- Dynamic user name, last message, time, and unread count
- Separate chat for each user
- Separate message history for each user
- Store messages inside the selected user's message array
- Save users and chat messages using LocalStorage
- Restore users and chat data from LocalStorage
- Preserve chat data after page refresh
- Save the currently selected chat index
- Dynamically create chat UI elements using JavaScript

## 🛠️ Technologies Used

- HTML
- Tailwind CSS
- JavaScript
- Fetch API
- LocalStorage API
- JSON
